
# ماشین حساب مهندسی (Scientific Calculator)

## معرفی پروژه
این پروژه یک ماشین حساب مهندسی ساده است که با استفاده از زبان برنامه نویسی پایتون (Python) طراحی و پیاده سازی شده است.

هدف از ساخت این پروژه، تمرین مفاهیم پایه برنامه نویسی پایتون و آشنایی با ساخت یک برنامه کاربردی است.

## امکانات برنامه
این ماشین حساب قابلیت انجام عملیات زیر را دارد:

1. جمع دو عدد (Addition)
2. تفریق دو عدد (Subtraction)
3. ضرب دو عدد (Multiplication)
4. تقسیم دو عدد (Division)
5. محاسبه توان (Power)
6. محاسبه جذر (Square Root)
7. محاسبه سینوس (Sin)
8. محاسبه کسینوس (Cos)
9. محاسبه تانژانت (Tan)
10. محاسبه لگاریتم (Log)
11. محاسبه لگاریتم طبیعی (Ln)
12. محاسبه فاکتوریل (Factorial)
13. نمایش عدد پی (Pi)

## زبان برنامه نویسی
- Python

## کتابخانه مورد استفاده
- math

## نحوه اجرای برنامه
ابتدا باید زبان برنامه نویسی پایتون روی سیستم نصب شده باشد.

سپس مراحل زیر را انجام دهید:

1. پوشه پروژه را در نرم افزار VS Code باز کنید.
2. ترمینال را باز کنید.
3. دستور زیر را وارد کنید:

```bash
python calculator.py
```

## مدیریت خطاها
در این برنامه برای جلوگیری از متوقف شدن ناگهانی برنامه از دستورات try و except استفاده شده است.

همچنین موارد زیر بررسی می شوند:
- جلوگیری از تقسیم بر صفر
- جلوگیری از محاسبه جذر اعداد منفی
- بررسی معتبر بودن ورودی های کاربر
- بررسی محدوده مجاز برای لگاریتم و فاکتوریل
