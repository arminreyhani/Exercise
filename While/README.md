
# پروژه حلقه While و تشخیص فشردن کلید کیبورد

## معرفی پروژه
این برنامه با استفاده از زبان برنامه نویسی پایتون نوشته شده است.

هدف آن نمایش یک شمارنده و بررسی فشرده شدن کلید A روی صفحه کلید است.

برنامه تا زمانی که کاربر کلید A را فشار نداده باشد، به اجرای خود ادامه می دهد.

## نحوه عملکرد برنامه
ابتدا شمارنده با عدد 1 شروع می شود.

سپس برنامه وارد یک حلقه while می شود که به صورت مداوم اجرا می شود.

در هر مرحله موارد زیر انجام می شود:

1. بررسی می شود که آیا کلیدی از صفحه کلید فشرده شده است یا خیر.
2. اگر کلید A یا a فشرده شود، برنامه متوقف می شود.
3. اگر کلید دیگری فشرده شود، پیام اشتباه بودن کلید نمایش داده می شود.
4. شماره شمارنده و پیام اجرای برنامه نمایش داده می شود.
5. شمارنده یک واحد افزایش پیدا می کند.
6. برنامه به مدت یک ثانیه متوقف می شود و سپس دوباره اجرا می شود.

## مفاهیم و کتابخانه های استفاده شده
- import: وارد کردن کتابخانه
- msvcrt: بررسی فشرده شدن کلیدهای صفحه کلید در ویندوز
- time: مدیریت زمان
- while True: ایجاد یک حلقه تکرار مداوم
- if و else: بررسی شرایط
- break: خروج از حلقه
- counter: متغیر شمارنده
- time.sleep(1): ایجاد یک ثانیه مکث
- print: نمایش اطلاعات
- input: در این پروژه استفاده نشده است.

## نحوه توقف برنامه
با فشردن کلید A یا a برنامه متوقف می شود.
