
# پروژه چاپ مستطیل با استفاده از حلقه For

## معرفی پروژه
این برنامه با استفاده از زبان برنامه نویسی پایتون نوشته شده است و هدف آن چاپ یک مستطیل از علامت ستاره (*) با تعداد سطر و ستون دلخواه کاربر است.

در این پروژه از حلقه های تودرتوی for استفاده شده است.

## نحوه عملکرد برنامه
ابتدا برنامه ارتفاع (Height) و عرض (Width) مستطیل را از کاربر دریافت می کند.

سپس با استفاده از دو حلقه for، تعداد مشخصی ستاره در سطرها و ستون ها چاپ می کند.

## مفاهیم استفاده شده در برنامه
- input: دریافت اطلاعات از کاربر
- int: تبدیل ورودی به عدد صحیح
- for: تکرار دستورات
- range: مشخص کردن تعداد دفعات تکرار
- print: نمایش خروجی
- end: جلوگیری از رفتن به خط بعدی هنگام چاپ هر ستاره
