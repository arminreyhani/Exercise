
# پروژه بررسی وضعیت قبولی دانشجو با استفاده از شرط If

## معرفی پروژه
این برنامه با استفاده از زبان برنامه نویسی پایتون نوشته شده است و هدف آن بررسی نمره دانشجو و مشخص کردن وضعیت قبولی یا مردودی او است.

در این برنامه از دستورات شرطی if و else استفاده شده است.

## نحوه عملکرد برنامه
ابتدا برنامه نمره دانشجو را از کاربر دریافت می کند.

سپس با استفاده از دستور if بررسی می کند که آیا نمره وارد شده بزرگتر یا مساوی 10 است یا خیر.

اگر نمره 10 یا بیشتر باشد، پیام You passed نمایش داده می شود.

در غیر این صورت پیام You failed نمایش داده می شود.

## مفاهیم استفاده شده در برنامه
- input: دریافت نمره از کاربر
- float: تبدیل ورودی به عدد اعشاری
- if: بررسی یک شرط
- else: اجرای دستورات در صورت برقرار نبودن شرط
- >=: عملگر بزرگتر یا مساوی
- print: نمایش نتیجه
